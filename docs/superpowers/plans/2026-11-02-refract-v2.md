# Refract v2 — product upgrade plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** make Refract feel like a shipping product: live GPU prescription mirror, optics X-ray, a real store embed, a product-grade landing with anime.js, and a share card — by 16:00 IST so the video can be recorded.

**Architecture:** Live mode renders the camera through a WebGL fragment shader that applies the same lens maths as `warpSource` (per-eye optical centre, cylinder axis, depth term) inside lens masks; frames, rings and HUD draw on a 2D overlay with the existing `drawFrame`. The embed is a standalone `public/embed.js` that opens the app in a modal iframe (`?embed=1`). All optics stay in `src/engine/*` (tested).

**Spec:** `docs/superpowers/specs/2026-11-02-refract-design.md` (unchanged goals; v2 adds live mode, X-ray, embed, share card).

## Global Constraints
- Same as v1 plan. anime.js for all new motion; respect reduced motion.
- No new runtime dependencies (WebGL by hand, no three.js).
- Live mode must hold ≥ 24 fps on a laptop; landmarks smoothed (no frame jitter).

## Review Focus
1. Camera denied / no face in live mode → clear state, no crash, offer photo mode.
2. Head turned or partly out of frame → frames hide instead of drawing garbage.
3. Embed opened from another origin → modal works, closes on Esc, no key exposure.
4. Reduced motion → landing still readable with no animation.
5. Mobile 390 px → live mirror fits, controls reachable.
