# Refract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Refract, a prescription-true eyewear + eye-makeup try-on web app built on YouCam APIs, before 2026-11-02 22:15 IST.

**Architecture:** React 19 + Vite 6 SPA using the UI kit (glass/HUD) and anime.js for motion. Pure-JS engine (`src/engine/*`) holds optics, fit, PD and makeup rules, shared by the browser and the server agent. A thin Node server (`server/*`, Express locally, one Vercel function in prod) proxies YouCam (key never in the browser) and runs the agent loop. MediaPipe Face Landmarker runs in the browser.

**Tech Stack:** React 19, Vite 6, animejs 4.5, motion, lucide-react, @mediapipe/tasks-vision 1.2, Express 4 (dev), node:test.

**Spec:** `docs/superpowers/specs/2026-11-02-refract-design.md`

## Global Constraints

- YouCam base URL `https://yce-api-01.makeupar.com`; key only in server env `YOUCAM_API_KEY`.
- Never re-create a YouCam task because polling timed out; poll every 3 s, give up after 120 s.
- Photos stay in the browser (localStorage); server holds nothing after a request.
- Cosmetic/retail language only; no medical claims; no invented statistics; label recorded data "Sample data · recorded YouCam response".
- No trademarked frame or makeup brand names; house brand "Refract".
- UI kit rules: tokens only for colour, 390 px and 1440 px with no horizontal scroll, ≤ 5 mobile tabs.
- Never add Claude/AI co-author lines to commits.

## Review Focus

1. Photo with no face / two faces / face too small → clear retake message, no YouCam call made.
2. Plano or near-zero Rx (|SE| < 0.5) → engine returns m = 1, studio shows "no visible lens effect", no compensating look forced.
3. Mixed-sign astigmatism (e.g. S +1.00 C −3.00) → thickness profile handles both signs without NaN.
4. YouCam error status (`error_src_face_too_small`, `CreditInsufficiency`, 401) → user-readable message and the replay option.
5. Very high Rx where every frame exceeds the edge target → recommend 1.74 + smallest frames and say so, never an empty list.
