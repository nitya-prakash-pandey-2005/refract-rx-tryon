# Demo video script (target 2:50, hard limit 3:00)

**Record:** Chrome at 1440 px with the bookmarks bar visible (Ctrl+Shift+B), your own face on the webcam, plus 5–10 s on a phone. No music, or royalty-free only. Name each YouCam API out loud and in a caption when it appears.

**Before recording:**
1. Open **Prescription** and set your real prescription. If you don't wear glasses, use the "−6.50 strong" preset and say so.
2. Run **YouCam analysis → Run YouCam analysis** on your own scan (about 34 units), so the oiliness in the Fit model is yours.
3. On **Check a pair**, drag the dashed **Check with Refract** button onto the bookmarks bar.
4. On **Check a pair**, press **Compare with the glasses I wear now** and type the size printed inside your own glasses' arm.
5. Open `/store/index.html` in a second tab.
